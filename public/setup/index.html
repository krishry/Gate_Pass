GATEPASS / SETUP

Connect your own room.

GatePass uses real Supabase email-and-password authentication. New signups become Guest profiles by default; Admin and VIP access is assigned only through protected administrator paths. There are no browser demo accounts.

Run locally

VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=your-public-anon-key
pnpm install
pnpm dev
pnpm typecheck
pnpm run build
pnpm run auth:probe

Production checklist

  • Enable the Supabase Email provider and choose the email-confirmation policy.
  • Apply supabase/migrations/001_gatepass_schema.sql.
  • Promote the first admin in the Supabase SQL editor, then use the protected promotion RPC for VIP assignment.
  • Configure the public URL and anon key in the deployment environment.
  • Keep the service-role key out of browser code and Git.
  • Run the positive signup, role, registration, pass, and check-in workflow with an approved disposable test account after migration.
